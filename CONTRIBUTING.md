# Contributing to Bharat Yojana

First off, thank you for considering contributing to Bharat Yojana! 

## Development Setup

1. Fork and clone the repository
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env` and fill in your local database credentials
4. Run the development server: `npm run dev`

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface, if applicable.
3. Your code should pass all standard linting checks (`npm run lint`).
4. Submit your PR using the standard template and wait for review.
